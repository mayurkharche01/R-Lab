R Laboratory Work

This repository contains all the practical exercises and lab manuals completed during the R Programming Laboratory. It includes Lab 1, Lab 2, Lab 3, and the entire lab manual, covering a wide range of R concepts such as descriptive statistics, data visualization, probability distributions, hypothesis testing, correlation, regression, and data science applications.

R is a powerful open-source programming language and environment widely used for statistical computing, data analysis, and graphical visualization. It provides a rich ecosystem of packages and tools that support data manipulation, machine learning, and advanced analytics, making it a key language for data scientists and researchers.

This repository serves as a complete reference for learning and practicing R programming concepts through structured lab sessions and practical implementations.
